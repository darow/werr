# werr

Минималистичный пакет для оборачивания ошибок с сохранением стека вызовов
и путей относительно корня проекта.

## Зачем

`github.com/pkg/errors` устарел, а стандартный `fmt.Errorf` не даёт
информации о том, *где именно* ошибка была обёрнута. `werr` решает
обе проблемы: API как у `pkg/errors`, путь как в `lazyerrors`,
но относительно корня вашего проекта.

## Установка

```bash
go get github.com/darow/werr
```

## Использование

```go
import "your/module/werr"

func doWork() error {
    if err := step(); err != nil {
        return werr.Wrap(err, "failed to do work")
    }
    return nil
}
```

`Wrap` поддерживает три формы:

```go
werr.Wrap(err)                              // без сообщения
werr.Wrap(err, "context")                   // со строкой
werr.Wrap(err, "failed to process id %d", id) // с форматом
```

## Формат вывода

Каждый `Wrap` добавляет уровень. Уровни печатаются от самого свежего
к самому глубокому, адрес отделён от сообщения пробелом:

```
cmd/main.go:85 (main.main) third: cmd/main.go:83 (main.main) second: cmd/main.go:81 (main.main) first: cmd/main.go:80 (main.main) root
```

GoLand распознаёт `cmd/main.go:85` как ссылку и переходит
на место последнего оборачивания по клику.

## Как ищется корень проекта

Один раз при первом вызове `Wrap`/`New`/`Errorf` пакет ищет `go.mod`,
поднимаясь вверх от текущей рабочей директории. Путь к файлам
выводится относительно этой директории.

## Совместимость

*   `errors.Is` / `errors.As` — через `Unwrap`.
*   `werr.Cause(err)` — достаёт исходную ошибку.
*   `werr.New`, `werr.Errorf` — создают новую ошибку с кадром.

## Ограничения

*   `skip` в `Wrap` (значение `2`) зависит от версии компилятора Go.
    Если вывод внезапно указывает на `werr.go`, поменяйте `skip`.
*   Стек захватывается только в момент вызова `Wrap`, а не при создании
    исходной ошибки.

## Лицензия

Внутренний пакет, используйте как хотите.
